# Changelog

*Last updated: 2026-08-26*

Notable changes to Kawa, most recent first. Kawa doesn't yet tag versioned
releases (see the [FAQ](faq.md) and [ROADMAP.md](https://github.com/makimoto-ai/kawa/blob/main/ROADMAP.md)
for where things are headed), so entries here are dated rather than tied to
a version number. For the Python SDK's own release history, see its
[CHANGELOG.md](https://github.com/makimoto-ai/makimoto-python/blob/main/CHANGELOG.md).

## 2026-07-01 — Launch

- Post-conversation transcription API, hosted in Singapore
- Open-source interactive playground and Python reference client (`demo/`)
- Five-stage transcription pipeline (audio resampling, voice activity detection with diarisation, noise filtering, speech-to-text, post-processing)
- Orchestration layer published under the MIT licence
- Developer portal and API documentation at makimoto.ai
